# RVTF Skills v0.4.0 Formal Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the validated RVTF Skills 0.4.0 candidate into a legally reusable, traceable GitHub release.

**Architecture:** Keep the existing implementation and version unchanged. Add project-owned MIT licensing and third-party compatibility notices, replace candidate wording with release wording, verify the generated archive contains the legal and release artifacts, then publish one immutable annotated tag and GitHub Release from the verified revision.

**Tech Stack:** Markdown, npm package metadata, Bash validation and packaging, Git annotated tags, GitHub Releases API.

---

### Task 2: Build and audit the release archive

**Files:**
- Generated: `dist/rvtf-skills-0.4.0.tgz`
- Generated: `dist/SHA256SUMS`

- [ ] **Step 1: Run the repository validation gate**

Run:

```bash

```

Expected: five Skills valid, 3 positive fixtures accepted, 4 exact negative fixtures rejected, and 39 mutations passed.

- [ ] **Step 2: Build the archive**

Run:

```bash
PYTHON_BIN=/usr/bin/python3 ./scripts/package.sh
```

Expected: `dist/rvtf-skills-0.4.0.tgz` with npm name/version `rvtf-skills@0.4.0`.

- [ ] **Step 3: Audit archive identity and legal files**

Run:

```bash
tar -tzf dist/rvtf-skills-0.4.0.tgz | sort
tar -xOf dist/rvtf-skills-0.4.0.tgz package/VERSION
tar -xOf dist/rvtf-skills-0.4.0.tgz package/package.json | node -e 'let s=""; process.stdin.on("data", d => s += d).on("end", () => { const p=JSON.parse(s); if (p.version !== "0.4.0" || p.license !== "MIT") process.exit(1); })'
```

Expected: the archive contains all five Skills, validators and fixtures, plus `LICENSE`, `THIRD_PARTY_NOTICES.md`, and `CHANGELOG.md`; both embedded version values are `0.4.0` and the embedded license is `MIT`.

- [ ] **Step 4: Create the checksum receipt**

Run:

```bash
(cd dist && shasum -a 256 rvtf-skills-0.4.0.tgz > SHA256SUMS)
(cd dist && shasum -a 256 -c SHA256SUMS)
```

Expected: `rvtf-skills-0.4.0.tgz: OK`.
