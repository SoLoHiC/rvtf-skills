# Changelog

All notable changes to RVTF Skills are documented in this file.

## [0.4.0] - 2026-08-06

This is the first formal RVTF Skills release.

### Added

- Canonical Requirement Trace and Acceptance Items with stable evidence and gap
  ownership.
- Actor-goal-path Journey Trace for ordered, causal, cross-boundary, recovery,
  and outcome-level acceptance.
- Bounded review governance with explicit applicability, coverage, freeze,
  remediation, closure, and controlled reopen decisions.
- Operational Economy for delivery-scope containment, evidence reuse and
  validity, tiered verification, review cadence, and Goal continuation without
  weakening host-native gates or delivery truth.
- Adapter Skills for Superpowers, Agent Skills, GSD Core, and BMAD Method at the
  revisions recorded in `THIRD_PARTY_NOTICES.md`.
- Deterministic schema fixtures and invariant mutations covering current and
  compatibility contracts.

### Compatibility

- Preserves legacy `0.3.0` inline evidence and unversioned legacy artifacts
  when they do not contain `0.4.0`-only fields.
- Keeps host lifecycle status, execution grouping, review authority, and
  continuation authority separate from RVTF closure truth.

### Verification

- Five packaged Skills pass metadata validation.
- Three positive schema fixtures are accepted and four exact negative fixtures
  are rejected.
- Thirty-nine invariant mutation checks pass.
- The release archive is generated by `scripts/package.sh` and published with a
  SHA-256 checksum.
